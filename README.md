# Odoo GCET Hackathon

## 🚀 Getting Started

Follow these steps after cloning the repo:

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd <project-folder>
```

### 2. Install dependencies
```bash
npm install
```
> This recreates the `node_modules` folder — only needed once after cloning.

### 3. Run the project
```bash
npm run dev
```

Open your browser at **http://localhost:5173**

---

## 🛠 Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS

```
src/
```
