================================================================================
AXIOS SETUP (src/lib/axios.ts)
================================================================================

Create a single Axios instance with:

1. baseURL: 'http://localhost:5000/api/v1'
2. Request interceptor:
   - Read access token from authStore (Zustand)
   - Attach as Authorization: Bearer <token> header
3. Response interceptor (401 handling):
   - If response is 401 and NOT a refresh request:
     a. Call POST /auth/refresh with refresh token
     b. If refresh succeeds → retry original request with new token
     c. If refresh fails → clear auth store → redirect to /login
   - If response is 403 → show toast "Insufficient permissions"
   - If response is 409 → show toast with conflict message
   - If response is 500 → show toast "Server error, try again"
4. All error toasts use sonner library

ZUSTAND STORES
================================================================================

authStore (src/stores/authStore.ts):
  State:
    user: User | null
    accessToken: string | null
    refreshToken: string | null
    isAuthenticated: boolean
  Actions:
    login(email, password) → calls POST /auth/login → stores tokens + user
    signup(data) → calls POST /auth/signup → stores tokens + user
    logout() → calls POST /auth/logout → clears everything → redirect /login
    setUser(user) → update user profile after edit
    hasRole(minRole) → boolean check against role hierarchy

uiStore (src/stores/uiStore.ts):
  State:
    sidebarOpen: boolean (default true, false on mobile)
    activeFilters: { type, status, warehouse, category, dateFrom, dateTo }
    theme: 'light' | 'dark'
  Actions:
    toggleSidebar()
    setFilter(key, value)
    resetFilters()
    setTheme(theme)

PAGE 1: LOGIN (/login)
----------------------
Layout: Centered card on gradient background. No sidebar.
Fields: Email (email input), Password (password input with show/hide toggle)
Buttons: "Sign In" (primary), "Forgot Password?" (link), "Create Account" (link)

------------------------
Layout: Same as login.

  1. Validate (password match, strength, email format)

  3. On success → redirect to /dashboard

----------------------------------------
Layout: Same as login. 3-step flow in one page.
Step 1: Enter email → POST /auth/forgot-password → show "OTP sent" message

Step 3: Enter new password + confirm → POST /auth/reset-password → redirect to /login
Timer: OTP expires in 10 minutes. Show countdown. "Resend OTP" button after 60s.
